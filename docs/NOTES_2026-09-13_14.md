## Recording-session structure (read-only analysis)

The Skeleton frame filenames carry recording times. `features/unit_times.csv` has one row per unit (`unit,t0,t1`), with
units named as in training_qa paths or `large_model_track_test/LM_test_XXXX`.

- **Test was recorded as 16 unbroken sessions.** Every test clip's nearest neighbour in time is another test clip
  (median gap 60 s). No test clip sits inside a training session (median gap 1.7 h), so there is no direct neighbour
  leak.
- **Consecutive same-user HAU clips (gap < 30 min), identical answer vs chance:**

  | Category | Identical | Chance |
  |---|---:|---:|
  | emotion | **0 / 725** | 0.043 |
  | sequence | 74 / 254 = 0.29 | 0.008 |
  | single | 0.23 | 0.04 |
  | multi | 0.13 | 0.01 |
  | combination | 0.10 | 0.003 |
  | HARn (same action) | 0.013 | — |

  The protocol repeats one activity script back to back, with a different manner each time.
- **Sequence:** consecutive clips with the same four-action option set have the identical true order 74 / 74 times;
  13 of 39 test sequence questions sit in such runs.
- **Emotion on test:** sub12 repeats the adverb in 43 / 127 consecutive test pairs, and the public file in 35 / 127.
- **Speed groups:** mean IMU intensity orders the adverbs cleanly, from `seriously`/`gracefully` (slow) to
  `rapidly`/`frantically` (fast). Consecutive clips share the fast/slow group 0.36 of the time (chance 0.50). Only
  16% of emotion questions are decided by speed group alone.
